# Page Topology

The reference site is a flight-plan portfolio. It opens with a boarding-pass entrance and progresses through a vertical timeline of large product imagery, canvas/WebGL scenes, hover states, and drag gestures.

Only one bounded component is adapted here:

```text

└── Royal porthole stage

    ├── antique-gold bezel
    ├── clipped viewport
    │   ├── generated landscape
    │   ├── atmospheric haze
    │   ├── draggable pearl-silk shade
    │   └── glass highlights
    ├── crest and medallion

```
