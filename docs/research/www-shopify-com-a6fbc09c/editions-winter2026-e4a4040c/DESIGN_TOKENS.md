# Design tokens

## Color

- Ink: `#292919`
- Paper: `#f7f7ee`
- Muted paper: `#dcdcd0`
- Shopify green: `#95bf47`
- Feature purple: `#5433eb`
- Black / white chapter surfaces: `#000000` / `#ffffff`

## Typography

- UI and large grotesk headings: Neue Montreal Bold, 700
- Editorial display: HW Cigars, 400
- Script accents: Imperial Script, 400
- Utility fallback observed in the source: Inter Variable

## Layout

- Desktop canvas: 1440 px reference width
- Tablet reference: 768 px
- Mobile reference: 390 px with 12 px outer gutters
- Thin hairline frames and radii from 8–32 px recur across cards and navigation.
- Motion is cinematic and scroll-led; media commonly fills its container with `object-fit: cover`.
